# Historias de usuario
 
Aplicación web para gestionar una colección de películas. Cada usuario puede ver las copias de películas que tiene (DVD, Blu-ray, etc.).
 
## Historias
 
**HU1 - Ver la página inicial**
Como visitante, quiero ver una página inicial con la descripción de la web y algunas películas recientes, para saber de qué trata antes de entrar.
 
**HU2 - Iniciar sesión**
Como usuario, quiero iniciar sesión con mi nombre de usuario y contraseña, para acceder a mi colección.
 
**HU3 - Ver mis copias**
Como usuario, quiero ver un listado de mis copias de películas, para saber qué tengo en mi colección.
 
**HU4 - Ver el detalle de una copia**
Como usuario, quiero entrar en una copia del listado, para ver su información completa.
 
**HU5 - Cerrar sesión**
Como usuario, quiero poder cerrar la sesión, para que nadie vea mi colección si uso un ordenador compartido.
 
**HU6 - Contactar**
Como visitante, quiero rellenar un formulario de contacto con mi nombre, correo y mensaje, para poder hacer una consulta o decir si tengo algún problema.
 
**HU7 - Moverme por la web**
Como usuario, quiero un menú para ir de una página a otra, para no perderme.
 
## Qué se hace en la Entrega 1
 
En esta entrega solo se hacen las páginas estáticas (inicio, login y contacto) con navegación entre ellas. El login y el contacto son simulados, todavía no hay base de datos. Las historias HU3, HU4 y HU5 se harán en las siguientes entregas.
